📝 Project Requirements: ระบบบริหารจัดการธุรกิจรีไซเคิล (Recycle Online)

System Overview (ภาพรวมระบบ):
ระบบแบ่งออกเป็น 2 แพลตฟอร์มหลักที่ทำงานร่วมกันผ่าน Database เดียวกัน:

Desktop Application (Back-Office): สำหรับแอดมิน/แคชเชียร์ ใช้ตั้งค่าระบบ จัดการฐานข้อมูลหลัก ดูรายงานเชิงลึก พิมพ์สลิป และ Export Excel

Mobile Application (Front-End/Operation): สำหรับพนักงานหน้าลาน ใช้ล็อกอิน ค้นหาข้อมูล ทำรายการชั่งน้ำหนักซื้อ-ขายแบบ Real-time และดูสรุปรายงานเบื้องต้น

💾 1. Database Schema & Master Data (ระบบจัดการข้อมูลพื้นฐาน)
เป็นส่วนที่จัดการบน Desktop เป็นหลัก เพื่อให้ Mobile ดึงไปใช้ ตัวระบบต้องมีการ Validate ข้อมูลป้องกันรหัสซ้ำซ้อน

1.1 หน่วยซื้อ-ขาย (Unit of Measurement - UOM):
Fields: รหัสหน่วย (PK), ชื่อหน่วย (เช่น กก., ลัง, ชิ้น, ใบ)

1.2 กลุ่มสินค้า (Product Categories):
Fields: รหัสกลุ่ม (PK), ชื่อกลุ่มสินค้า (เช่น กระดาษ, เหล็ก, สังกะสี, ทองแดง)

1.3 ข้อมูลสินค้า (Products):
Fields: รหัสสินค้า (PK), ชื่อสินค้า, รหัสกลุ่มสินค้า (FK), รหัสหน่วย (FK)
Pricing: รองรับเรตราคารับซื้อหลายเกรด (ราคาซื้อ@A, ราคาซื้อ@B, ราคาซื้อ@C, ราคาซื้อ@D) และ ราคาขาย@
Stock: สต๊อกคงเหลือ (คำนวณอัตโนมัติจากการซื้อ/ขาย)

1.4 ข้อมูลพนักงาน (Employees):
Fields: รหัสพนักงาน (PK), ชื่อ-นามสกุล, ที่อยู่ 1, ที่อยู่ 2, เบอร์โทรศัพท์, หมายเหตุ

1.5 ข้อมูลผู้รับซื้อ / ลูกค้า (Buyers):
Fields: รหัสผู้ซื้อ (PK), ชื่อ-นามสกุล, ที่อยู่, เบอร์โทรศัพท์

1.6 ข้อมูลผู้ขาย / ซัพพลายเออร์ (Sellers):
Fields: รหัสผู้ขาย (PK), เกรดลูกค้า (เช่น A, B, C - เพื่อผูกกับราคาซื้อ), เลขบัตรประชาชน/นิติบุคคล, ชื่อ, ที่อยู่, เบอร์โทรศัพท์, ทะเบียนรถ
Feature: รองรับการอัปโหลดรูปภาพโปรไฟล์ผู้ขาย และการสร้าง QR Code/Barcode ประจำตัว

1.7 ข้อมูลประเภทค่าใช้จ่าย (Expense Categories):
Fields: รหัสค่าใช้จ่าย (PK), รายละเอียด (เช่น ค่าน้ำมัน, ค่าแรง), หมายเหตุ

1.8 ข้อมูลประเภทรายได้อื่นๆ (Other Income Categories):
Fields: รหัสรายได้ (PK), รายละเอียด (เช่น ค่าบริการ), หมายเหตุ

1.9 ข้อมูลผู้ประกอบการ (Company Profile):
Fields: ชื่อร้าน/บริษัท, ที่อยู่, เบอร์โทรศัพท์ (ข้อมูลส่วนนี้จะถูกดึงไปแสดงเป็น Header บนหัวรายงานและสลิป)

📱 2. Core Operations (ระบบปฏิบัติการซื้อ-ขาย)
ระบบ Transaction หลักที่เชื่อมต่อระหว่างจุดชั่งน้ำหนัก (Mobile) กับระบบแคชเชียร์ (Desktop)

2.1 การซื้อประจำวัน (Daily Buy):
Desktop: แสดงฟอร์มสร้างบิล (เลขที่เอกสาร, วันที่, ข้อมูลผู้ขาย, ทะเบียนรถ) Data Grid แสดงรายการ (รหัส, รายการ, จำนวน, หักภาชนะ, คงเหลือ, ราคา@, รวมเงิน) ฟังก์ชันแก้ไข/ลบ/พิมพ์สลิป (F8/F9)
Mobile (หน้าลาน):
Flow: สแกนบัตรสมาชิก (QR) -> เลือกลูกค้า -> เลือกกลุ่มสินค้า -> เลือกสินค้า -> ป้อนราคา/กก. -> แสดงตัวเลขน้ำหนักขนาดใหญ่ (รองรับการดึงค่าจากเครื่องชั่งอัตโนมัติ) -> กรอกค่าหักภาชนะ/สิ่งเจือปน
ปุ่ม Action: ซื้อรายการอื่นต่อ (Add to cart), บันทึก/ส่งข้อมูล (Submit to Desktop)

2.2 การขายประจำวัน (Daily Sell):
ลักษณะ UI และ Flow การทำงานเหมือนการซื้อประจำวัน แต่เปลี่ยนจาก "ข้อมูลผู้ขาย" เป็น "ข้อมูลผู้ซื้อ" และทำหน้าที่ ตัดสต็อก ออกจากระบบ

2.3 บันทึกรายรับอื่นๆ & บันทึกจ่ายได้อื่นๆ:
Desktop: เลือกวันที่, ผู้บันทึก (ล็อกอิน), รหัสประเภท, จำนวนเงิน, เอกสารอ้างอิง, หมายเหตุ
Mobile: สามารถเรียกดูรายการย้อนหลังตามสาขาและช่วงวันที่ได้ (แสดงเป็น Data Table)

📊 3. Reports & Analytics (ระบบรายงานและสรุปผล)
รองรับการดูผ่านระบบ และสามารถ Export เป็น Excel ได้ (มีหัวกระดาษเป็นชื่อกิจการ)

3.1 รายงานข้อมูลพื้นฐาน (Master Data Reports):
สามารถสั่งพิมพ์รายการ หน่วยซื้อขาย, กลุ่มสินค้า, รายการสินค้า, รายชื่อผู้ซื้อ, รายชื่อผู้ขาย ได้จากระบบ

3.2 รายงานธุรกรรมประจำวัน (Transaction Reports):
รายงานการซื้อประจำวัน & รายงานการขายประจำวัน:
Filters: วันที่ถึงวันที่, กลุ่มสินค้า, รายการสินค้าเฉพาะตัว, ผู้ขาย/ผู้ซื้อเฉพาะราย
รูปแบบการจัดกลุ่ม: เรียงตามรหัส, เรียงตามบุคคล, หรือสรุปตามเลขที่เอกสารบิล
Excel Export Logic: เมื่อ Export ไป Excel ระบบจะต้อง แยก Sheet (Tab) ตาม "กลุ่มสินค้า" ให้โดยอัตโนมัติ

3.3 รายงานการเงินและการจัดการ (Financial & Inventory Reports):
รายงานรายรับอื่นๆ / รายจ่ายอื่นๆ: สรุปยอดตามช่วงวันที่ เลือกดูเฉพาะรายการได้ (Mobile ดูได้)
สรุปการเงินประจำวัน (Daily Financial Summary):
Data Table Column: วันที่ | รายได้จากขาย | รายได้อื่นๆ | รายจ่ายจากการซื้อ | ค่าใช้จ่ายอื่นๆ | ส่วนต่าง (กำไร/ขาดทุนสุทธิของวัน)
มีแถบ Status bar หรือแถบสียอดรวมด้านล่าง (Mobile ดูได้)
รายงานสินค้าคงเหลือ (Inventory/Stock):
ค้นหาตามชื่อหรือกลุ่มสินค้า
Data Table Column: รหัส | ชื่อสินค้า | ราคาเฉลี่ย | สต๊อกคงเหลือ | ยอดรวม (มูลค่า)
คำนวณมูลค่ารวมของสต็อกทั้งหมดไว้ด้านล่างสุด (Mobile ดูได้)

⚙️ 4. System & Security (ระบบตั้งค่าและความปลอดภัย)
4.1 การจัดการผู้ใช้งาน (User Management):
Desktop:
เพิ่ม/แก้ไข/ลบ ชื่อผู้ใช้ (Username) และ รหัสผ่าน (Password)
การกำหนดสิทธิ์ (Permissions): เป็นรูปแบบ Checkbox ให้ติ๊กเลือกเมนูที่อนุญาตให้เข้าถึงได้ (เช่น ข้อมูลพนักงาน, ข้อมูลสินค้า, บันทึกการรับซื้อ, รายงานสรุปการเงิน ฯลฯ)

4.2 Mobile Authentication:
หน้า Login หน้าแรกรองรับการกรอก Username / Password ปกติ
รองรับฟีเจอร์ "สแกนบัตรเพื่อเข้าใช้งาน" (QR Code Login) สำหรับพนักงาน

UI/UX Concept & Layout Requirements (ข้อกำหนดด้านหน้าตาแอป):
Desktop Color Scheme: โทนสีฟ้า-ขาว, ไอคอนเมนูแบบวงกลมมีกราฟิกชัดเจน แบ่ง Tab การทำงานเป็นหมวดหมู่ (ข้อมูลพื้นฐาน, บันทึกซื้อ-ขาย, รายงาน, ตั้งค่า) โครงสร้างหน้าต่างซ้อนทับกัน (MDI - Multiple Document Interface)
Mobile Color Scheme: พื้นหลังไล่สีโทนฟ้า-น้ำเงิน ปุ่มเป็นแบบ 3D (มีเงาและมิติ) ขนาดใหญ่เพื่อให้กดง่ายขณะทำงานหน้าลาน ใช้ Font ขนาดใหญ่โดยเฉพาะจุดแสดง "น้ำหนัก"
