# วิธีเปิดระบบสาธิต

ระบบสาธิตใช้ฐานข้อมูลแยกชื่อ `recycle_demo` ไม่แตะข้อมูลจริงหรือข้อมูลพัฒนา (dev)
ข้อมูลที่บันทึกในระบบสาธิตจะยังอยู่ เปิดครั้งหน้าก็เห็นของเดิม

## ห้ามเปิดระหว่างที่การตรวจระบบกำลังทำงาน

ถ้าการตรวจระบบอัตโนมัติ (prove_all) กำลังทำงานอยู่ start_demo จะไม่ยอมเปิดและบอกว่าให้รอ
รอจนการตรวจเสร็จ แล้วค่อยเปิดใหม่ อย่าลบไฟล์ล็อกเอง

## เปิด

1. ในโฟลเดอร์โปรเจกต์ เข้าไปที่ `tools\owner`
2. ดับเบิลคลิก `start_demo.cmd`
3. รอจนหน้าต่างดำขึ้นว่า `START_DEMO_OK` (ครั้งแรกใช้เวลาหลายนาที) แล้วกดปุ่มใดก็ได้เพื่อปิดหน้าต่างนั้น
   ระบบยังทำงานต่อ

ถ้าขึ้นว่า `START_DEMO_REFUSED` ให้อ่านบรรทัดภาษาไทยที่อยู่ใต้มัน จะบอกสาเหตุและวิธีแก้
(เช่น หน่วยความจำไม่พอ ให้ปิดโปรแกรมตามรายการที่แสดง)

## ปิด

ดับเบิลคลิก `tools\owner\stop_demo.cmd` จะปิดเฉพาะสิ่งที่ start_demo เปิดไว้ และแสดงรายการที่ปิด
Docker ยังเปิดอยู่ต่อ เพราะใช้ร่วมกับงานอื่น

## หน้าต่างที่จะเห็น

| หน้าต่าง | คืออะไร |
|---|---|
| หน้าต่างดำที่ขึ้น `DEMO_SERVER` | เซิร์ฟเวอร์ของระบบ ทั้งโทรศัพท์และคอมพิวเตอร์คุยกับตัวนี้ ห้ามปิด |
| หน้าต่างดำชื่อ `Metro` | ตัวส่งโค้ดของแอปไปให้โทรศัพท์จำลอง ห้ามปิด |
| หน้าต่างรูปโทรศัพท์ | โทรศัพท์จำลอง (Android) มีแอปรับซื้อเปิดอยู่ |
| หน้าต่างดำชื่อ `Desktop program` | ตัวสร้างโปรแกรมคอมพิวเตอร์ ห้ามปิด |
| โปรแกรมหลังร้าน | โปรแกรมบนคอมพิวเตอร์ ดูบิล ข้อมูลหลัก รายงาน |

## เข้าสู่ระบบ

- รหัสร้าน: **3PTNQH8Y** — start_demo พิมพ์รหัสร้านให้ทุกครั้งที่เปิด (ถ้าฐานข้อมูล recycle_demo
  ถูกสร้างใหม่ทั้งหมด รหัสร้านจะเปลี่ยน ให้ดูจากบรรทัด `shop code (รหัสร้าน)` ในหน้าต่างของ start_demo)
- ชื่อผู้ใช้: `admin` (ผู้ดูแล) และ `staff` (พนักงาน)
- รหัสผ่าน: ไม่พิมพ์ไว้ที่นี่ และ start_demo ไม่แสดง ดูได้ที่ไฟล์ `server\app\seeddata.py`
  บรรทัด `TENANT_A_PASSWORD` (ของ admin) และ `TENANT_A_STAFF_PASSWORD` (ของ staff)

โปรแกรมหลังร้านตั้งที่อยู่เซิร์ฟเวอร์และรหัสร้านไว้ให้แล้ว ใส่แค่ชื่อผู้ใช้และรหัสผ่าน
ในโทรศัพท์ ถ้าแอปถามรหัสร้าน ให้ใส่รหัสร้านด้านบน

## ถ้าแอปในโทรศัพท์ขึ้นว่า ออฟไลน์

แอปยังบันทึกบิลได้ตามปกติ บิลจะรอส่งและส่งเองเมื่อต่อเซิร์ฟเวอร์ได้ ไม่หาย

แอปถูกตั้งไว้ให้เรียกเซิร์ฟเวอร์ที่ `http://192.168.1.238:8000` ให้ตรวจตามลำดับ

1. หน้าต่าง `DEMO_SERVER` ยังเปิดอยู่ไหม ถ้าปิดไปแล้ว ให้ปิดระบบด้วย stop_demo แล้วเปิดใหม่
2. ตอนเปิด start_demo ขึ้นคำเตือนว่า IP ของเครื่องไม่ตรงไหม ถ้าขึ้น แปลว่าเครื่องนี้ไม่ได้ใช้ IP
   `192.168.1.238` แล้ว วิธีแก้คือให้เครื่องนี้ได้ IP นั้นเสมอ (จองที่อยู่ให้เครื่องนี้ในเราเตอร์
   หรือตั้ง IP แบบคงที่ใน Windows) แล้วปิดและเปิดระบบใหม่
3. ถ้าข้อ 1 และ 2 ปกติแต่ยังออฟไลน์ อาจเป็นไฟร์วอลล์ของ Windows บล็อกพอร์ต 8000
   ให้อนุญาต Python ในไฟร์วอลล์สำหรับเครือข่ายส่วนตัว
